# Demo video script (2–3 min)

1. **Hook (15 s)** — "Developers decide in 5 seconds whether to clone your repo. Which README hero wins that 5 seconds? We tested it with Flagsmith."
2. **Creator flow (30 s)** — paste a repo URL → card → share panel → Discord unfurl with OG image.
3. **The variants (30 s)** — normal + incognito window side by side: `architecture_first` vs `quickstart_first`. Show the Flagsmith flag, its variations and the 50/50 experiment.
4. **The metric (20 s)** — copy the clone command → show `developer_intent` arriving in Flagsmith. Mention the `bounce_under_5s` guardrail.
5. **Results (45 s)** — Flagsmith results page: n per arm, intent rate, guardrail. Say the decision out loud per the plan.
6. **Advice loop (20 s)** — `/r/owner/repo/stats`: audit + "Copy optimized README hero".
7. **Segment (optional, 15 s)** — `visual_heavy_repos` override routing to `demo_gif_first`.
8. **Close (10 s)** — what we'd test next.
